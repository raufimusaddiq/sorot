  (`bun:sqlite`, zero runtime deps). Same routes, JSON shapes and DB file;
  `backend/src/db.ts` migrates pre-ALTER databases.

  `linker = "hoisted"` for Next/Jest).

  `start.ps1 -Dev` adds hot-reload UI on :3000. `.env.local` → `.env.development`
  so prod builds stay same-origin.
- **Fixes found while porting/testing**
  - backend: stale-object save could flip CANCELLED back to RUNNING; `.part`
    cleanup deleted other jobs' downloads; cancel now kills the child process;
    retry reuses a finished download; Bun idle timeout raised to 255 s.
  - frontend: polling not resumed after reload; QUEUED not treated as active

  - ai-pipeline: `generate_clip_title` gave a hashtag-only title when text
    opened with punctuation; date-dependent test in `test_discover.py`.
- **Removed**: Java backend, `frontend/package-lock.json`, dead `ai-pipeline/utils/`.

## Part 3 — face-tracking reframe; OpenCV pin

mode — user to run `git push origin master`.

- New `ai-pipeline/reframe.py`: 2 fps samples → faces (MediaPipe if present,
  else Haar) → per-frame centre (group if it fits the 9:16 window, else largest

## Part 4 — scoring face detection fix

(user approved; this shifts scores/tiers):

## Part 8 — NVENC probe, scene-cut crops, doubled captions

- **NVENC was never used**, in Docker or on the host: render.py probed with a
  128x128 test frame, below NVENC's minimum ("Frame Dimension less than the
  minimum supported value"), so the probe always said no and every encode ran
  on x264. Probe frame is 256x256 now; with Part 7's `video` capability the
  container probe returns True.
- **Crops move on scene cuts**: the sampling decode also runs ffmpeg's scene
  score (`split` → `select='gt(scene,0.3)',showinfo`); plan_track puts a move
  on the cut between the last sample on the old framing and the confirming
  samples. Clip 1's wide→close-up switch lands at 2.16 s (was 2.0 s, ~0.5 s of
  table). Profile cascades only run when the frontal pass finds nobody
  (tracking 19.7 s → 10.9 s for 60 s).
- **Doubled caption lines** (user report): build_ass held each highlight for
  ≥ 0.3 s even when the next word came sooner; libass stacks overlapping
  events, drawing the line twice. 2,984 of 5,837 events in the Fadil import
  overlapped. Events now end at the next event's start; clip 1 regenerated:
  181 events, 0 overlaps.
- Fresh run of the Fadil import on the rebuilt image: **COMPLETED** (first
  time). RENDER 366 s (was ~870 s), VARIATION 118 s with 9 real files in
  `variations/{videoId}/`. SUBTITLE was still 581 s: subtitle.py has its own
