# antislop Delivery Gate: desktop design (Phase 1)

antislop active: during (session override). Subject: `desktop/design/sorot-desktop.figcraft` and the exports under `desktop/design/frames/` and `desktop/assets/`.
Design Read (declared before building, `specs/003-native-desktop-app/design.md`): ENERGY 2 / RHYTHM 2 / MOTION 2, **MOTION 3 on the job screen** (owner decision 2026-11-15: rune-fx at signature moments; see `fx.md`). The gate was re-run after that change.
Method: generated by `gen/build.ts`, then inspected from the exported PNGs (dark and light) and the layer tree. Frames looked at one by one: home, shell, job, clips (1280 and 1920), editor, publish (light), learning, readiness, welcome-library (light), generate-build, generate-storylines, generate-verdict, settings-connections (light), the states sheet (light), motion notes, brand. The rest come from the same builders (`ui.ts`, `components.ts`) and the same tokens. Numbers come from `gen/contrast.ts` and `gen/verify.ts`.

Scope of this gate: a design, not a running app. Items that only running code can prove are marked "design scope" and name what closes them. None is claimed as run.

Defects found while running the gate and fixed before this report:
1. R-25 / R-32 (focus visibility): the `beam` amber used as a focus ring or selected-control edge measured 1.64:1 on the light `bg` (needs 3:1). Fixed: focus rings, focused fields, selected-control edges and emphasis strokes use `beamText` (5.46:1 light, 10.35:1 dark). The beam fill stays on fills, heads and the falloff, which are decorative.
2. R-38: the welcome screen showed this machine's real folder path. Replaced with generic sample paths.
3. R-17 / R-36: the Learning subtitle claimed that no number on screen was not the user's while showing sample numbers. Reworded to what the product does ("Sorot tidak mengisi angka sendiri"); the menu bar of every frame says "Pratinjau desain, data contoh".
4. Verdict screen: three unlabelled preview boxes got "Adegan n" labels.

Re-run after the rune-fx decision (2026-11-15): beam head heat states, grain on the beam fill, stage-done ripple, job-done burst, motion blur on rank change, fluted glass on the palette and the transport. Re-checked: R-01, R-04, R-10, R-12, R-13, R-19, R-25, R-39, the dial rows of Block 3. Result below; no new defect, one owner-instructed exception (R-04, see Block 2).

## Block 1: Hard Gate (all must be "no")

- [x] Em dash in text (R-02): no. A search for the em dash over `gen/*.ts` (the only source of UI text) finds none.
- [x] Overflow, text escaping, broken layout (R-03): no at 1280x800 and 1920x1080. Inspected frames show no clipped or overflowing text; long copy wraps. Desktop app: no mobile target (spec sizes 1280 and 1920).
- [x] Statistics without a real source (R-17): no. Every figure is a labelled sample, flagged in the menu bar of every frame; the product rule (no invented numbers) is in the Learning copy.
- [x] Fictional testimonials (R-18): no. None designed.
- [x] Assets made without instruction (R-23): no. The icon and wordmark were requested by the owner on 2026-11-15 (task T009) and wait for approval at the Phase 1 checkpoint. No people, avatars or logos of others. Thumbnails are empty boxes, not fake photos.
- [x] Navigation to nonexistent pages (R-24): no. Rail: Beranda, Klip, Temukan, Generate, Belajar, Setelan, each a screen in this file. Menu bar items are OS menus.
- [x] Text below WCAG AA (R-25): no. `gen/contrast.ts` checked 28 pairs in both modes; the lowest text pair is `pass` on `bg` in light at 4.64:1; boundaries are at least 3:1 (`edge` on `surface`, light, 3.82). Output is in `README.md`.
- [x] Buttons, dropdowns, forms that do nothing (R-26): no. Each control maps to a route or behaviour in the interaction inventory below. Disabled controls (Lihat klip, Latih ulang, Posting sekarang, Pulihkan) carry their reason next to them.
- [x] Missing empty, loading or error state (R-27): no. The `states-*` sheets design all three for Klip, Pekerjaan, Editor, Terbitkan, Belajar, Temukan, Setelan and Generate; each names the cause and the next action, including the Generate AI gate.
- [x] Generic FAQ (R-28): no. There is no FAQ.
- [x] Keyboard and visible focus (R-32): no, at design scope. Every control component has a `focused` variant (2 px `beamText` ring; the primary action adds the glow); the keyboard map is in the palette and Settings. The real Tab, Enter and Escape order is proved by the L2 Runtime tests and L3 `--script` flows, not claimed here.
- [x] Feature added by patching with an external script (R-33): no. The design is generated by `gen/build.ts` calling figcraft commands; exports are not post-processed.
- [x] Theme toggle breaks a mode (R-34): no. Every screen exists in `dark` and `light` through the same variables; light frames inspected (publish, welcome, connections, states, clips). Literal colours that cannot bind a variable are the video frame (always dark) and the label on the beam fill (`#17191C`, 9.51:1 on `#F0B44C`).
- [x] Delivered without a run or click-through (R-35): no, at design scope. The design was built and exported by script and the exports were looked at. The click-through of the real app is Phase 10; the inventory below is its script.
- [x] Fabricated security, compliance, performance or customer claims (R-36): no. The only claims are behaviours already specified (keys masked, nothing posts automatically, local-first).
- [x] Built without direction (R-37): no. Direction, dials and Design Read are in `design.md`, written before any frame.
- [x] Realistically-styled fabricated content (R-38): no after fix 2. Names are generic ("Saluran contoh A", "@akunanda"); titles are labelled sample.
- [x] Control without cursor, native element, name, states, label, alt, reduced motion, valid ARIA, lang, title, landmarks, or zoom (R-39): no, at design scope. Controls have default, hover, pressed, focused, disabled and error variants; fields have visible labels; verdicts carry their word; reduced-motion equivalents are in `Motion notes`. Native elements, names and landmarks are Rune accessibility roles, asserted through `--tree` in the L2 tests.
- [x] Media without dimensions, late content without reserved space, unmeasured performance numbers (R-40): no. The clip stage (9:16) and thumbnails have fixed dimensions; no performance number is reported.

## Block 2: Purpose-Gate (technique allowed, reason written)

- [x] Gradient or glow as default (R-01): no. One gradient, the beam falloff, with its reason in the `Beam` component description (it depicts light). Glow only on the beam head (a heat light: cool, warming, hot), the hook marker head and the primary action ring; never more than 2 per screen (job: 1, editor: 1). The only texture is grain on the beam fill, with its reason in the `Beam` description (it gives the light a body); nowhere else.
- [x] Generic icons (R-04): no. Seven drawn icons (play, pause, cancel, reveal, retry, chevron, check), 1.5 px stroke, square ends, each with its reason in the component description. No sparkle, robot or orb icon; Generate is labelled by name. The rail has no icons. Owner-instructed exception, recorded: the job-done burst (`SparkleParams::burst`) is a one-shot particle effect on "Lihat klip" (12 plain 4 px squares that fade in 0.5 s), requested by the owner on 2026-11-15; it is motion, not a glyph or an icon, and it is dropped under reduce-motion.
- [x] Monospace, wide-tracked uppercase, unreasoned typeface (R-06): no. Instrument Sans only (reason in `design.md`), tabular figures for numbers. Uppercase appears only as verdict words (PASS, REVIEW, SKIP) at normal tracking.
- [x] Background grid, blueprint, dots (R-07): no.
- [x] Decorative arrows on buttons (R-08): no. Buttons carry labels only.
- [x] Capsule badges without function (R-09): no. The only badges are verdict marks (radius 2, outline plus word), each a real status. No pill above a heading.
- [x] Glass on more than 1-2 surfaces (R-10): no. Exactly two, now fluted glass with frost (12 and 20): the transport bar over video and the command palette. Neither frame shows more than one (clips: transport, shell: palette).
- [x] Large shadow on every component (R-12): no. Shadow only on floating layers (palette, dialog, toast). Panels are flat with a 1 px divider.
- [x] Glow everywhere (R-13): no. See R-01. No glowing cards, badges, borders or icons.
- [x] Identical feature cards without hierarchy (R-14): no. In Storylines the chosen card is larger and ringed. The Kit catalogue and the Ideas row are uniform on purpose: peers of one kind carry equal weight, and the chosen idea carries the ring.
- [x] Template animations or motion that contradicts the declared dial (R-19): no. MOTION 2 everywhere, MOTION 3 on the job screen only (owner decision). Nine moments, each with a stated purpose and a reduced-motion version, in `Motion notes`; every rune-fx layer is a one-shot or driven by real engine progress (heat follows PROGRESS and cools by itself, once); no looping animation; indeterminate waits show elapsed time.
- [x] Generic illustrations (R-22): no. None; empty states use type and the beam.
