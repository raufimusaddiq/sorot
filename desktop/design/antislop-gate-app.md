`desktop/Cargo.toml`, manager-approved) and evidence inputs (`desktop/scripts/headless/us2-review-export.json`,

T-36 approved copy). Gate run on 2026-11-20, Windows, `cargo clippy --all-targets -- -D warnings`,

run, or a command reproduced in "Evidence commands" below. No raw verify logs were kept: the commands
and their pass counts are quoted here instead. A defect is a FAIL reported to the manager, not silently
fixed.

(named in the "Honest design-scope items" list below; 21 rows are also tagged "design-scope PASS"). We do not claim that
every PASS is run-backed: rows whose only evidence is "seen in snapshots" or an absence in source are
design-scope calls, and a few rows (R-18, R-28, R-40) have no dedicated run assertion at all. No behaviour
defect was found. Verification: clippy exit 0; `cargo test --test suite` 134 passed, 0 failed;
`cargo test -p sorot-desktop-core` 37 passed, 0 failed; `bun design/gen/verify.ts` and
`bun design/gen/contrast.ts` both printed PASS. Counts and any FAIL were reported to the manager via
`rig say manager`.

One known nondeterminism (not an app defect, tracked separately as T-37): T-30's click-through test writes
wall-clock time into `design/clickthrough.md` (the `publish/schedule/now` row sets minute/hour/day from the
current time), so the file changes on every run. T-31 reverted that 2-line hunk to base
(`git checkout feat/native-desktop-app -- desktop/design/clickthrough.md`); pinning the test clock is T-37.
