# Icon assets

Source: the `Brand` page of `desktop/design/sorot-desktop.figcraft`, exported by `desktop/design/gen/build.ts --export`
(see `desktop/design/README.md`). `icns/` and `ico/` hold the exported PNGs.

`icon.icns` and `icon.ico` are built from them by `bun desktop/assets/icon/build-icons.ts`; do not edit them by hand.
`icon-512.png` is the Linux icon, `tray-template.svg` the one-colour tray image (macOS template, tinted on Linux).
