# Bundled fonts

All fonts are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org),
which allows bundling and embedding in videos. Files are the `latin` subsets from the
`@fontsource/*` packages (Latin script covers Indonesian and English).

| Family | Weights | Source |
|---|---|---|
| Plus Jakarta Sans | 400, 700 | @fontsource/plus-jakarta-sans |
| Inter | 400, 700 | @fontsource/inter |
| Bebas Neue | 400 | @fontsource/bebas-neue |
| Lora (serif) | 400, 700 | @fontsource/lora |
